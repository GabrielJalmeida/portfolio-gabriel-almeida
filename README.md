# Gabriel Almeida Portfolio — V8

V8 keeps the approved visual direction and strengthens the two weakest narrative areas of the portfolio: **How I Work** and **About**.

## V8 changes

### Recruiter access
- discreet `CV ↗` link added to the primary navigation
- location is now visible directly in the hero: Praia Grande, SP · Brazil
- bilingual CV options remain available in Contact

### How I Work
The previous generic five-step methodology was replaced by a shorter evidence-driven loop:

1. **Understand** — user need, constraints and business rules
2. **Structure** — routes, data, boundaries and behavior
3. **Verify** — tests, CI, accessibility and real-device feedback

Each step points back to actual portfolio work rather than presenting methodology as a generic manifesto.

A small **AI-assisted workflow** note has also been added with transparent language about how AI is used to accelerate prototyping, implementation and iteration while Gabriel remains responsible for requirements, validation, testing and final product decisions.

### About
- headline changed to **“Learning by building real systems.”**
- clearer positioning as someone early in the software career without weakening the work already demonstrated
- career transition from customer-facing / operational work into software is now part of the story
- visual career path added without relying on exact dates
- new **Learning Now** block
- current direction and availability simplified
