def calcular_score(produto, perfil):
    score = 0

    if produto["tipo_pele"] == perfil.tipo_pele:
        score += 3
    elif produto["tipo_pele"] == "todos":
        score += 1

    if perfil.sensivel and produto["pele_sensivel"]:
        score += 2

    return score

How I work / 01—05

Structure before polish.

Not a rigid methodology. A repeatable way to reduce ambiguity before adding complexity.

  1. 01Frame

    Make the real problem explicit.

  2. 02Model

    Define rules, data and constraints.

  3. 03Build

    Turn the model into working software.

  4. 04Verify

    Test behavior, not just appearance.

  5. 05Refine

    Improve what reality exposes.
